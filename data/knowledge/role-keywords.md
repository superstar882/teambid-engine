# Most-requested skills by role

Group: Market · Related vault file: `Job/Resume/rules/10-keyword-bank.md` · 9 sources, 12 findings

## Findings (strongest sources first)

- Agentic AI skills are the fastest-growing AI skill cluster in postings. **0.06% of postings in 2024 to 0.23% in 2025 (+280%), about 90,000 US postings** (Lightcast, 2026-04-13; high)
  - Takeaway: Use 'agents' and 'agentic' keywords where true (CrewAI/MCP hackathon agent).
- Python adoption jumped sharply year over year, and the most-used languages remain JavaScript, HTML/CSS, SQL, and Python. **Python +7 percentage points 2024 to 2025; JS 66%, HTML/CSS 61.9%, SQL 58.6%, Python 57.9%** (Stack Overflow, 2025-07; high)
  - Takeaway: Python + SQL + TypeScript covers the most-used stack.
- Python is the most in-demand specialized skill in US job postings. **258,674 postings; up ~30% from 2024 and 391% vs 2013-15** (Lightcast, 2026-04-13; high)
  - Takeaway: Keep Python first in the skills line.
- Roughly a quarter of AI-mentioning postings give little context for how AI will be used in the role. **roughly a quarter** (Indeed Hiring Lab, 2025-10-28; medium)
  - Takeaway: Some 'AI' postings are buzzword-only; screen for concrete AI work before applying.
- About half of US postings that mention AI describe building new AI tools or directly using AI models (July 2024 to June 2025). **52%** (Indeed Hiring Lab, 2025-10-28; medium)
  - Takeaway: Builder-type AI roles are a large share of AI postings; match 'build' language with shipped AI products.
- TypeScript became the most-used language on GitHub by contributors in August 2025, while Python dominates AI projects. **TypeScript +1M contributors (+66% YoY); Python in 582,196 AI repos** (GitHub, 2025-10-28; high)
  - Takeaway: Python + TypeScript is the right two-language pitch for full-stack AI roles.
- LinkedIn's top skills for AI engineers are LangChain, RAG, and PyTorch. **Top skills: LangChain, retrieval-augmented generation (RAG), PyTorch** (Dice, 2026-01-14; high)
- Data pipelines, SQL, and Python are table stakes in data engineer postings; Spark, Snowflake, Airflow, Databricks, and dbt are common but not universal. **Pipelines 74%, SQL 71%, Python 71%, AWS 44%, Spark 33%, Snowflake 31%, Airflow 29%, Databricks 29%, dbt 24%, Kafka 17%** (DEV Community (InterviewStack.io data), 2026-05-09; medium)
- In 703 US data engineer postings from Indeed, SQL, Azure, Python, and ETL were the most requested skills. **SQL 79.4%, Azure 74.5%, Python 73.7%, ETL 57%, AWS 49.5%, Spark 41.1%, ML 29.9%, Kafka 16.2%, Snowflake 11.7%** (365 Data Science, 2026-04-23; medium)
- No single skill appears in half of software engineer postings; Python leads, then Java and AWS. **Python 34.8%, Java 27.3%, AWS 26.5%, SQL 21.9%, Kubernetes 18.6%, TypeScript 17.7%, Docker 17.2%, React 15.2%, ML 6.7%, LLMs 5.0%** (InterviewStack.io, 2026-05-20; medium)
  - Takeaway: Add AWS/Docker/Kubernetes where honest; they appear far more than LLM keywords in generic SWE posts.
- LangChain is the most-requested agent framework in agentic engineering postings, followed by LangGraph, LlamaIndex, CrewAI, and AutoGen. **LangChain 392, LangGraph 256, LlamaIndex 150, CrewAI 106, AutoGen 74 of 1,135 listings** (agentic-engineering-jobs.com, 2026-05; medium)
- Python appears in nearly all agentic postings and MCP shows up in a meaningful minority. **Python 91-96%; MCP 17-24%** (agentic-engineering-jobs.com, 2026-05; medium)
  - Takeaway: Mention MCP experience (Composio MCP from the hackathon) explicitly.
